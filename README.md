# RenewIT
Document Expiration Reminder System
RenewIT is a Python-based application designed to help users manage and track document expiry dates efficiently. It automatically reminds users before documents expire, ensuring timely renewals.

## 🚀 Features
- Add, update, and delete documents.
- Set custom reminders before expiry.
- View all documents and their expiry dates.

## 🛠️ Tech Stack
- Python
- MySQL (for data storage)
